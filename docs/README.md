## 🌟 Quick Feature Matrix

1. **Interactive Swipe Discovery Deck**: Physics-driven swipe gestures with `motion/react`, 3-card layered background depth, keyboard shortcuts (`←`, `→`, `↑`, `Z`), and live match scores.
2. **Centralized Verified Job Opportunities**: Over 1,048 authenticated tech roles from industry leaders and startups with verified source URL preservation.
3. **Pre-Flight Multi-Factor ATS Compatibility**: Transparent 5-factor scoring formula ($S, K, E, D, T$) auditing candidate resumes against target job descriptions *before* application submission.
4. **AI STAR Mock Interview Simulator**: Tailored role-specific technical and behavioral questions with hands-free voice dictation (Web Speech API) and multi-factor evaluation across Clarity, Technical Depth, and STAR Impact.
5. **Resume & Career Intelligence**: Automated skill extraction, work history parsing, and career roadmap progression visualization.
6. **Applications Tracking Pipeline**: Visual Kanban board and list view with automated stage transitions (`APPLIED` → `REVIEWING` → `INTERVIEWING` → `OFFERED` → `REJECTED`).
7. **Recruiter & Talent Portal**: Candidate screening dashboard with ATS score ranking and one-click role publishing.
8. **Admin Command Center**: Real-time telemetry monitoring AI model latency, database health, and network-wide activity audit streams.
9. **Zero-Secret Isolation**: Server-side isolation of all secrets and credentials with seamless heuristic offline fallback.
